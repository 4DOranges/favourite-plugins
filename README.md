# Favourite Plugins
A personal annoyance of mine is that I have all my plugins, WIP & finished, cluttering the Plugin Hub list.
So the idea behind this one is simple: Allow people to favourite plugins and show only those in the list.

## Enabling the plugin
1. Put the fav-plugins folder in your plugin development folder (\Jagex\Runescape-Beta\\).
2. In the game, open the developer console and type:
   ```
   prf
   pon fav-plugins
   ```

## Using the plugin
* Open the Plugin Hub and select the "Manage" tab.
* The ★/⭐ on the far right of the "search" bar toggles between showing only your Favourited plugins, or all of them.
* Each plugin has a ✰/⭐ in front of its name. Click this to toggle the "Favourite" status of the plugin.

This plugin does not in any way interact with other plugins, it simply helps you filter the list.

## Known issues
* Enabling/disabling a plugin causes the ⭐ to disappear until the tab is re-opened.
